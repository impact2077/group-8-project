# FitPlan Studio – Trang Nội dung wellness

## Tên đề tài
FitPlan Studio (BTL-29) – website lập kế hoạch tập luyện và duy trì thói quen với 4 vai trò: người tập, huấn luyện viên, điều phối cộng đồng, quản trị viên.

## Trang đã thực hiện
**Nội dung wellness** (Điều phối cộng đồng).

## Mục đích
Cho điều phối cộng đồng đăng và quản lý các bài viết về sức khỏe, thói quen tập luyện.

## Chức năng chính
- Thêm, sửa, xóa bài viết gồm tiêu đề và nội dung.
- Kiểm tra dữ liệu: tiêu đề và nội dung không được để trống.
- Bảng danh sách rút gọn nội dung; xác nhận trước khi xóa.
- Các trạng thái: đang tải, lỗi tải (bật bằng ô "Giả lập lỗi tải" ở chân trang), chưa có bài viết nào.
- Responsive cho Desktop, Tablet và Mobile.

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Grid, Media Query), JavaScript thuần (DOM, Event). Không dùng framework.

## Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt. Dữ liệu mẫu nằm trong mảng JavaScript ở đầu file `js/main.js`, không cần máy chủ.

## Cấu trúc thư mục
```
├── index.html
├── css/style.css
├── js/main.js
├── assets/
└── README.md
```

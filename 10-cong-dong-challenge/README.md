# FitPlan Studio – Trang Challenge

## Tên đề tài
FitPlan Studio (BTL-29) – website lập kế hoạch tập luyện và duy trì thói quen với 4 vai trò: người tập, huấn luyện viên, điều phối cộng đồng, quản trị viên.

## Trang đã thực hiện
**Challenge** (Điều phối cộng đồng).

## Mục đích
Cho điều phối cộng đồng tạo và quản lý các thử thách, xem nhanh số thử thách đang chạy và lượt tham gia.

## Chức năng chính
- Thêm, sửa challenge và lưu trữ hoặc khôi phục thay vì xóa hẳn.
- Thẻ thống kê: đang chạy, tổng lượt tham gia, đã lưu trữ, tự cập nhật khi dữ liệu đổi.
- Kiểm tra dữ liệu: tên và thời gian không được để trống.
- Các trạng thái: đang tải, lỗi tải (bật bằng ô "Giả lập lỗi tải" ở chân trang), chưa có challenge nào.
- Responsive cho Desktop, Tablet và Mobile.

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Grid, Media Query), JavaScript thuần (DOM, Event). Không dùng framework.

## Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt. Dữ liệu mẫu nằm trong mảng JavaScript ở đầu file `js/main.js`, không cần máy chủ.

## Cấu trúc thư mục
```
├── index.html
├── css/style.css
├── js/main.js
├── assets/
└── README.md
```

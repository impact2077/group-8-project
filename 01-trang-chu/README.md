# FitPlan Studio – Trang Trang chủ

## Tên đề tài
FitPlan Studio (BTL-29) – website lập kế hoạch tập luyện và duy trì thói quen với 4 vai trò: người tập, huấn luyện viên, điều phối cộng đồng, quản trị viên.

## Trang đã thực hiện
**Trang chủ** (trang dùng chung).

## Mục đích
Giới thiệu FitPlan Studio và dẫn người dùng tới đăng nhập hoặc đăng ký.

## Chức năng chính
- Banner giới thiệu với hai nút Bắt đầu ngay và Đăng nhập.
- Bốn thẻ tính năng nổi bật: kế hoạch gợi ý, theo dõi tiến độ, huấn luyện viên, cộng đồng.
- Các liên kết sang trang khác hiển thị thông báo vì mỗi trang do một thành viên làm riêng.
- Responsive cho Desktop, Tablet và Mobile.

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Grid, Media Query), JavaScript thuần (DOM, Event). Không dùng framework.

## Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt. Dữ liệu mẫu nằm trong mảng JavaScript ở đầu file `js/main.js`, không cần máy chủ.

## Cấu trúc thư mục
```
├── index.html
├── css/style.css
├── js/main.js
├── assets/
└── README.md
```

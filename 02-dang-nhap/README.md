# FitPlan Studio – Trang Đăng nhập

## Tên đề tài
FitPlan Studio (BTL-29) – website lập kế hoạch tập luyện và duy trì thói quen với 4 vai trò: người tập, huấn luyện viên, điều phối cộng đồng, quản trị viên.

## Trang đã thực hiện
**Đăng nhập** (trang dùng chung).

## Mục đích
Cho người dùng đăng nhập bằng email, mật khẩu và chọn vai trò để vào đúng khu vực.

## Chức năng chính
- Kiểm tra dữ liệu: bỏ trống email hoặc mật khẩu, email sai định dạng.
- Trạng thái đang đăng nhập (nút bị khóa trong lúc chờ).
- Báo lỗi khi mật khẩu dưới 6 ký tự; đăng nhập thành công hiển thị lời chào theo vai trò.
- Responsive cho Desktop, Tablet và Mobile.

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Grid, Media Query), JavaScript thuần (DOM, Event). Không dùng framework.

## Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt. Dữ liệu mẫu nằm trong mảng JavaScript ở đầu file `js/main.js`, không cần máy chủ.

## Cấu trúc thư mục
```
├── index.html
├── css/style.css
├── js/main.js
├── assets/
└── README.md
```

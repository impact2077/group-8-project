# FitPlan Studio – Trang Analytics

## Tên đề tài
FitPlan Studio (BTL-29) – website lập kế hoạch tập luyện và duy trì thói quen với 4 vai trò: người tập, huấn luyện viên, điều phối cộng đồng, quản trị viên.

## Trang đã thực hiện
**Analytics** (Quản trị viên).

## Mục đích
Cho quản trị viên xem tổng quan hệ thống: số người dùng, số buổi tập đã ghi, tỉ lệ hoàn thành và phân bố buổi tập theo ngày trong tuần.

## Chức năng chính
- Ba thẻ thống kê: người dùng, buổi tập đã ghi, tỉ lệ hoàn thành.
- Biểu đồ thanh số buổi tập theo thứ trong tuần, vẽ bằng HTML và CSS.
- Lọc theo khoảng thời gian (tất cả hoặc 7 ngày gần nhất), số liệu tính lại ngay.
- Các trạng thái: đang tải, lỗi tải (bật bằng ô "Giả lập lỗi tải" ở chân trang), chưa có dữ liệu.
- Responsive cho Desktop, Tablet và Mobile.

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Grid, Media Query), JavaScript thuần (DOM, Event). Không dùng framework.

## Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt. Dữ liệu mẫu nằm trong mảng JavaScript ở đầu file `js/main.js`, không cần máy chủ.

## Cấu trúc thư mục
```
├── index.html
├── css/style.css
├── js/main.js
├── assets/
└── README.md
```

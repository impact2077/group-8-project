# FitPlan Studio – Trang Quản lý người dùng

## Tên đề tài
FitPlan Studio (BTL-29) – website lập kế hoạch tập luyện và duy trì thói quen với 4 vai trò: người tập, huấn luyện viên, điều phối cộng đồng, quản trị viên.

## Trang đã thực hiện
**Quản lý người dùng** (Quản trị viên).

## Mục đích
Cho quản trị viên quản lý tài khoản, phân vai trò và khóa hoặc mở khóa người dùng.

## Chức năng chính
- Thêm, sửa người dùng gồm họ tên, email và vai trò.
- Khóa hoặc mở khóa tài khoản thay vì xóa hẳn, nhãn trạng thái Hoạt động hoặc Bị khóa.
- Kiểm tra dữ liệu: họ tên, email không được để trống, email phải đúng định dạng.
- Các trạng thái: đang tải, lỗi tải (bật bằng ô "Giả lập lỗi tải" ở chân trang), chưa có người dùng nào.
- Responsive cho Desktop, Tablet và Mobile.

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Grid, Media Query), JavaScript thuần (DOM, Event). Không dùng framework.

## Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt. Dữ liệu mẫu nằm trong mảng JavaScript ở đầu file `js/main.js`, không cần máy chủ.

## Cấu trúc thư mục
```
├── index.html
├── css/style.css
├── js/main.js
├── assets/
└── README.md
```

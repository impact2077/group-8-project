# FitPlan Studio – Trang Thư viện bài tập

## Tên đề tài
FitPlan Studio (BTL-29) – website lập kế hoạch tập luyện và duy trì thói quen với 4 vai trò: người tập, huấn luyện viên, điều phối cộng đồng, quản trị viên.

## Trang đã thực hiện
**Thư viện bài tập** (Quản trị viên).

## Mục đích
Cho quản trị viên quản lý dữ liệu bài tập gốc của hệ thống.

## Chức năng chính
- Thêm, sửa bài tập; lưu trữ hoặc khôi phục thay vì xóa hẳn.
- Kiểm tra dữ liệu: tên bài tập và nhóm cơ không được để trống.
- Nhãn trạng thái Hoạt động hoặc Lưu trữ.
- Các trạng thái: đang tải, lỗi tải (bật bằng ô "Giả lập lỗi tải" ở chân trang), chưa có bài tập nào.
- Responsive cho Desktop, Tablet và Mobile.

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Grid, Media Query), JavaScript thuần (DOM, Event). Không dùng framework.

## Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt. Dữ liệu mẫu nằm trong mảng JavaScript ở đầu file `js/main.js`, không cần máy chủ.

## Cấu trúc thư mục
```
├── index.html
├── css/style.css
├── js/main.js
├── assets/
└── README.md
```

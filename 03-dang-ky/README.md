# FitPlan Studio – Trang Đăng ký

## Tên đề tài
FitPlan Studio (BTL-29) – website lập kế hoạch tập luyện và duy trì thói quen với 4 vai trò: người tập, huấn luyện viên, điều phối cộng đồng, quản trị viên.

## Trang đã thực hiện
**Đăng ký** (trang dùng chung).

## Mục đích
Cho người tập tạo tài khoản mới với họ tên, email và mật khẩu.

## Chức năng chính
- Kiểm tra từng ô: để trống, email sai định dạng, mật khẩu dưới 6 ký tự.
- Báo lỗi khi email đã được đăng ký trước đó.
- Đăng ký thành công hiển thị thông báo và xóa nội dung form.
- Responsive cho Desktop, Tablet và Mobile.

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Grid, Media Query), JavaScript thuần (DOM, Event). Không dùng framework.

## Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt. Dữ liệu mẫu nằm trong mảng JavaScript ở đầu file `js/main.js`, không cần máy chủ.

## Cấu trúc thư mục
```
├── index.html
├── css/style.css
├── js/main.js
├── assets/
└── README.md
```
